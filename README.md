# ۲۰۴۸ — نسخه‌ی حرفه‌ای (تک‌فایل HTML)

یک بازی ۲۰۴۸ کامل و «آماده‌ی بازی» در **یک فایل HTML**: `index.html`
بدون هیچ وابستگی، بدون اینترنت و بدون سرور — کافی است فایل را در مرورگر باز کنید.

## شروع سریع

- **ساده‌ترین راه:** روی `index.html` دوبار کلیک کنید.
- **با سرور محلی (اختیاری):**
  ```bash
  python3 -m http.server 8000
  # سپس http://localhost:8000 را باز کنید
  ```
- **در موبایل:** فایل را به گوشی منتقل کنید و با مرورگر بازش کنید (کاملاً آفلاین کار می‌کند).

## ویژگی‌ها

| دسته | جزئیات |
| --- | --- |
| گیم‌پلی | صفحه ۴×۴، تولید تصادفی ۲/۴ (۹۰٪ → ۲)، ادغام استاندارد ۲۰۴۸، تشخیص پایان بازی |
| کنترل | کلیدهای جهت‌دار، `W A S D`، کشیدن انگشت (سوایپ)، دکمه‌های روی صفحه |

| ادامه‌ی بازی | بازی نیمه‌کاره به‌صورت خودکار ذخیره و در بازدید بعدی ادامه داده می‌شود |
| واگرد | تا ۳۰ حرکت به عقب؛ سابقه‌ی واگرد هم بعد از بستن مرورگر باقی می‌ماند |
| ظاهر | پوسته‌ی تیره/روشن/سیستم، رنگ‌بندی اختصاصی خانه‌ها تا ۸۱۹۲، انیمیشن ظهور و ادغام، جلوه‌ی برنده‌شدن |
| تنظیمات | صدا، پوسته، ارقام فارسی/انگلیسی، انیمیشن‌ها، پاک‌کردن داده‌ها |

| موبایل | چیدمان واکنش‌گرا، پشتیبانی از ناحیه‌ی ایمن (notch)، صفحه‌ی لمسی بدون زوم ناخواسته |

## کلیدهای میان‌بر

| کلید | کار |
| --- | --- |
| `↑ ↓ ← →` یا `W A S D` | حرکت خانه‌ها |
| `U` | واگرد حرکت |
| `N` | بازی جدید |
| `M` | روشن/خاموش کردن صدا |
| `?` یا `F1` | راهنما |
| `Esc` | بستن پنجره‌ی باز |

## ذخیره‌سازی در مرورگر

همه‌چیز محلی است؛ هیچ داده‌ای به سروری فرستاده نمی‌شود.

| کلید | محتوا |
| --- | --- |
| `fa2048:state:v1` | رکورد فعلی (`best`)، تنظیمات، آمار، بازی جاری، تاریخچه‌ی واگرد و فهرست رکوردها |

نکته‌ها:
- در حالت ناشناس یا وقتی فضای ذخیره‌سازی مرورگر مسدود است، بازی بدون خطا اجرا می‌شود و فقط رکوردها نگه داشته نمی‌شوند.
- با «حذف همه داده‌ها» در تنظیمات، تمام رکوردها، آمار و بازی ذخیره‌شده پاک می‌شود.

## پشتیبانی مرورگر

Chrome/Edge 90+، Firefox 90+، Safari 15.4+، مرورگرهای موبایل iOS/Android.
در مرورگرهای قدیمی‌تر بازی کار می‌کند، اما ممکن است برخی افکت‌های بصری (مثل blur و انیمیشن ادغام) ساده‌تر نمایش داده شوند.

## یادداشت توسعه

منطق بازی از رندر جدا است و همه‌ی وضعیت در یک شیء `game` نگه داشته می‌شود؛
حرکت‌ها روی مدل داده شبیه‌سازی می‌شوند و سپس DOM با انیمیشن به‌روزرسانی می‌شود.
رندر خانه‌ها با `transform: translate(...)` بر پایه‌ی اندازه‌های واقعی صفحه انجام می‌شود
تا انیمیشن‌ها نرم و جابه‌جایی‌ها بدون پرش باشند.
