# بازی ۲۰۴۸ — 2048 Game

یک بازی کامل و حرفه‌ای ۲۰۴۸ در قالب **یک فایل HTML واحد** (`index.html`) — بدون نیاز به هیچ فریم‌ورک یا بیلد.

## امکانات

- 🎮 گیم‌پلی کامل ۲۰۴۸: حرکت، ادغام، برد در ۲۰۴۸ و امکان ادامه بازی
- ✨ انیمیشن‌های روان (لغزش کاشی‌ها، ظهور، ادغام و پاپ امتیاز)
- ⌨️ کنترل با کلیدهای جهت‌دار و WASD + کلید `U` برای بازگشت
- 📱 پشتیبانی کامل از کشیدن انگشت (Swipe) و دکمه‌های جهت در موبایل
- ↩️ دکمه بازگشت (Undo) — حتی بعد از باخت می‌توانید یک حرکت برگردید
- 🔊 افکت‌های صوتی با Web Audio API (بدون فایل خارجی) + دکمه روشن/خاموش
- 🎉 کنفتی و پیام تبریک هنگام رسیدن به ۲۰۴۸
- 💾 **ذخیره خودکار در مرورگر (localStorage):**
  - ادامه بازی از همان‌جایی که رها کردید (حتی بعد از بستن صفحه)
  - رکورد (بهترین امتیاز)
  - آمار: تعداد بازی‌ها، بردها، بیشترین کاشی، مجموع حرکت‌ها
  - تنظیمات صدا
- 🌙 رابط کاربری فارسی و راست‌چین (RTL) با اعداد فارسی و طراحی تیره مدرن
- 📐 کاملاً واکنش‌گرا (Responsive) برای موبایل و دسکتاپ

## اجرا

کافی است فایل `index.html` را در مرورگر باز کنید، یا یک سرور محلی راه بیندازید:

```bash
python3 -m http.server 8000
# سپس: http://localhost:8000
```
